# 🚆 Train Speed Analysis

A computer vision-based system for detecting trains and estimating their speed from video.

## Features

- Train detection using YOLO
- Real-time speed estimation
- Overspeed detection
- Speed limit monitoring
- Live video processing
- Visual dashboard

## Technologies

- Python
- OpenCV
- YOLO
- NumPy
